Claro, siguiendo tu mismo patrón, para el servicio de credit-proposal (donde está el PDF Cover), los comandos serían estos:

1. BUILD
Construye la imagen usando el Dockerfile específico de service_credit_proposal:

powershell
docker build -f services/service_credit_proposal/Dockerfile -t credit-proposal-cover-pdf:dev .
2. TAG
Etiqueta la imagen con la URI del repositorio ECR (nota que el nombre del repo es credit-proposal-cover-pdf):

powershell
docker tag credit-proposal-cover-pdf:dev 051826715282.dkr.ecr.us-east-1.amazonaws.com/credit-proposal-cover-pdf:dev
3. LOGIN
(Igual que siempre, solo necesitas hacerlo una vez por sesión):

powershell
aws ecr get-login-password --region us-east-1 | docker login --username AWS --password-stdin 051826715282.dkr.ecr.us-east-1.amazonaws.com
4. PUSH
Sube la imagen al ECR:

powershell
docker push 051826715282.dkr.ecr.us-east-1.amazonaws.com/credit-proposal-cover-pdf:dev
5. DEPLOY con Serverless
Aquí la variable de entorno clave es ECR_IMAGE_URI_CREDIT_PROPOSAL_COVER (según tu archivo 
service_credit_proposal.yml
):

powershell
$env:ECR_IMAGE_URI_CREDIT_PROPOSAL_COVER="051826715282.dkr.ecr.us-east-1.amazonaws.com/credit-proposal-cover-pdf:dev"
npx serverless deploy --config service_credit_proposal.yml --stage dev
